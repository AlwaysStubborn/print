> **生效声明**：本文档为本人投资行为的最高准则。  
> **制定日期**：2026-06-23  
> **版本**：1.0（首版，随认知深化可修订，修订须书面记录理由）  
> **核心使命**：永远不再重复 2021 年的路径。

## 第零章：创伤档案（我为什么需要这份宪法）

### 2021 年的教训

| 项目 | 记录 |
|------|------|
| 入场时间 | 2021 年牛市亢奋期 |
| 入场方式 | 被市场赚钱效应吸引，追高入场，买在阶段性高点附近 |
| 最深浮亏 | 约 **-30%** |
| 最终行为 | 恐惧驱动下割肉离场（情绪止损，非系统止损） |
| 根本原因 | 思维懒惰（不懂产品就买入）、无投资系统、无仓位纪律 |

### 更早的教训

- 曾尝试定投，**半年即中断**
- 曾因听小道消息、追热点而亏损
- 共同根源：将决策权让渡给消息、情绪和他人

### 从疼痛中提炼的铁律

1. 我真实的风险承受力远低于市场波动幅度（实测崩溃点约 -30%，系统目标设为 -5%）
2. 没有系统的坚持 = 在恐惧中必然放弃
3. 「再不上车就来不及了」是最昂贵的幻觉
4. 知识是变化的，纪律是不变的——先把握不变的东西

> **本宪法的首要目标，不是追求最高收益，而是永远不再重复 2021 年的路径。**

## 第一章：投资身份与总纲

### 1.1 我是谁

我是一名**长期绝对收益投资者**，不是交易员、不是预测者、不是赌徒。

- 我的身份是：本投资体系的**立法者与守护者**
- 市场是：信息源和波动来源
- 各类平台（雪球、券商、AI）：工具提供商，不是决策主体

### 1.2 根本目标

| 维度 | 目标 |
|------|------|
| 时间框架 | **10 年以上**（十年翻倍，彻底放弃一年翻倍） |
| 收益预期 | 长期年化 **4%–6%**（风险约束下的合理补偿） |
| 最大回撤 | 组合整体不超过 **5%** |
| 操作频率 | 极低——大部分时间系统静默运行 |
| 成功标准 | 行为稳定性 + 心态友好，而非短期排名 |

### 1.3 核心哲学（四大支柱）

**世界观**：市场短期不可预测，放弃一切形式的择时和预测。

**风险观**：回报来自对系统性风险的理性承担。市场只为无法分散的系统性风险给予预期回报补偿（回报补贴系统性风险）。

**人性观**：最大敌人是自己。行为金融学陷阱（处置效应、损失厌恶、从众、锚定）必须通过系统规则隔离。

**方法论**：投资逻辑必须与时间框架严格匹配——不用短线逻辑做长线交易，反之亦然。

### 1.4 最高原则

> 一切决策以防止因**思维懒惰**坠入「粪坑」为第一要务。

「粪坑」= 不假思索买入复杂产品、盲从平台推荐、情绪驱动追涨杀跌、因怕麻烦而放弃制定规则。

任何让我感到「省心」「省事」的诱惑，都需用十倍警惕审视。

### 1.5 根本原则

| 原则 | 内容 |
|------|------|
| 资金原则 | 只用**五年以上绝对闲钱**。可以少投，绝不用急钱。 |
| 思维原则 | **养老金思维**——只进不出，等待增值，退休前默认不动用。 |
| 市场原则 | 接受有效市场假说，承认短期不可预测，不将时间浪费在预测上。 |
| 实践原则 | **逐步脱敏**——从低波动起步，确认心态友好后再增加风险暴露。 |
| 制订原则 | 方案制订上要勤奋，定完了之后就不能勤奋更换。 |

## 第二章：不为清单（Stop Doing List）

以下行为被永久禁止，无例外：

- [ ] **不杠杆、不借钱投资**
- [ ] **不懂不做**——说不清产品是什么、怎么赚钱、最大风险是什么，就不买
- [ ] **不盲目择时**——不因「明天可能涨/跌」而操作
- [ ] **不追热点、不听小道消息**
- [ ] **不因短期新闻、宏观事件、社群讨论而操作**
- [ ] **不购买不理解的产品**（包括复杂衍生品、结构产品）
- [ ] **不用短线逻辑做长线交易，不用长线逻辑为短线错误开脱**
- [ ] **不使用绝对指数点位作为买卖依据**（如「比上次高点只高 150 点所以是低点」）
- [ ] **不一次性大额建仓权益类资产**（必须定投或分批）
- [ ] **不照搬任何外部方案**（平台推荐、群组共识、AI 建议）——可借鉴框架，绝不复制结论
- [ ] **单一卫星资产仓位不超过总资产的 5%**
- [ ] **单一个股仓位不超过总资产的 5%**（若未来尝试个股）

## 第三章：资产配置法

### 3.1 风险认知

| 风险类型 | 定义 | 策略 |
|----------|------|------|
| 系统性风险 | 市场整体风险，不可通过分散消除 | 理性承担，获取市场补偿 |
| 非系统性风险 | 个股/单一事件风险，可分散 | 通过宽基指数和资产配置消除 |

### 3.2 目标配置结构（终极方案）

当完成脱敏、宪法稳定运行后，组合目标比例为：

| 层级 | 比例 | 角色 | 工具示例 |
|------|------|------|----------|
| **核心压舱层** | **70%** | 绝对稳健，控制回撤 | 鹏华稳泰30天滚动持有债券A (019528)、广发招财短债A (006672) |
| **稳健增强层** | **20%** | 获取权益收益，波动可控 | 沪深300指数增强（如富国100038）、固收+（如安信稳健增值001316） |
| **机会与对冲层** | **10%** | 分散风险，对冲极端事件 | 黄金ETF联接（如华安黄金易000216） |

**权益内部结构**（占总量 20% 部分）：
- 核心（70%）：沪深300指数增强——A 股大盘蓝筹
- 增强（30%）：固收+基金——控制回撤前提下增加收益弹性

**明确排除或严格限制**：
- 纳斯达克100、中证1000 等小盘/高波动品种：仅可作为卫星，合计 ≤ 5%
- 美元债 QDII、海外 FOF：波动大，不作为「债券压舱石」

### 3.3 当前执行方案（脱敏阶段 v1）

> 在系统稳定运行、经历至少一个完整市场周期前，采用更保守的过渡配置。

| 层级 | 当前比例 | 说明 |
|------|----------|------|
| 核心压舱层（纯债） | **85%–90%** | 以债基为主，确保心态友好 |
| 稳健增强层（权益试水） | **5%–10%** | 沪深300 小额定投 + 三分法试验（1000 元） |
| 机会与对冲层 | **0%–5%** | 暂不配置，或极低比例黄金 |

**过渡原则**：
- 每 6 个月评估一次心态和宪法执行情况
- 若权益仓位 -5% 浮亏时内心平静 → 可考虑将权益提升至 10%–15%
- 若出现焦虑、失眠、频繁查看账户 → 立即降回当前比例，不强行加码

### 3.4 脱敏进阶路线图

| 阶段 | 权益仓位上限 | 进入条件 | 预计时间 |
|------|-------------|----------|----------|
| 第一阶段（当前） | 5%–10% | 宪法 v1.0 生效 | 现在 |
| 第二阶段 | 10%–15% | 连续 6 个月执行定投无中断；权益 -5% 时心态平稳 | 6 个月后 |
| 第三阶段 | 15%–20% | 经历一次 -10% 市场回撤仍坚持纪律 | 1–2 年后 |
| 终极方案 | 20%（总上限） | 系统自动化运行 2 年以上，穿越完整牛熊 | 2–5 年后 |

**永不上调的情况**：出现「再不上车就晚了」的冲动、因社群情绪改变计划、宪法执行中断超过 1 个月。

### 3.5 个人养老金账户（补充层）

| 项目 | 规则 |
|------|------|
| 年度额度 | 顶格 **1.2 万元/年**（若个税税率 > 3%） |
| 定位 | 退休资产的「保底」部分，与主账户独立 |
| 产品选择 | 低费率养老 FOF 或指数基金 |
| 纪律 | 存入后视同主账户，同样只进不出 |

## 第四章：操作执行法

### 4.1 决策流程（每次操作前必走）

```
触发想法 → 对照宪法条款 → 填写检查清单 → 48h冷却 → 执行/放弃
```

**强制检查清单**（任一不满足则禁止操作）：

- [ ] 我能说清这项投资的最大风险是什么吗？
- [ ] 它在我的总资产中占比符合预定纪律吗？
- [ ] 我是因为近期涨跌/新闻/社群情绪而想操作吗？
- [ ] 这个操作触发了宪法中哪一条具体规则？
- [ ] 它会让我的心态友好状态受到破坏吗？

### 4.2 买入纪律

#### 4.2.1 入场条件（防 2021 重演）

任何权益类资产的新增买入，**必须同时满足**：

1. 本宪法已生效且配置方案书面确定
2. 采用**定额定投**，禁止一次性大额建仓
3. 投入资金为五年以上绝对闲钱
4. 若出现「再不上车就晚了」的冲动 → 启动 48 小时冷却期，重读创伤档案

#### 4.2.2 估值触发式定投规则

**数据源**（固定使用，不随意更换）：理杏仁 / 乌龟量化 / 且慢（选定一个后写入执行记录）

**参考指数**：沪深300（PE-TTM，近 10 年历史百分位）

| PE 百分位 | 定投操作 |
|-----------|----------|
| 10%–30% | 基础定投金额 **M** |
| < 10% | 定投金额提升至 **2M**，可动用不超过总资产 5% 的预备金追加一次 |
| 30%–50% | 定投金额 **0.75M**（偏低但不极端） |
| 50%–70% | 定投金额 **0.5M** |
| > 70% | 定投金额 **0.25M** 或暂停当月定投，不卖出 |
| > 85% | 暂停定投，仅持有；若比例严重偏离可启动再平衡卖出 |

> **注意**：A 股「牛短熊长」，PE 百分位 60% 未必代表高估。买入阈值偏保守（< 30% 才加码），是刻意选择。

**基础定投金额 M**：每月收入的 _____%（建议 5%–15%，以「几乎无感」为原则，可持续比金额大小重要一万倍）

**扣款日**：每月 _____ 日（发薪日后 1–3 日内）

#### 4.2.3 个股 vs 大盘（若未来涉及个股）

| 对象 | 纪律 |
|------|------|
| 个股 | 保留盈利头寸，舍弃亏损头寸；亏损达 **15%** 无条件止损 |
| 大盘指数基金 | 越跌越买（定投），逢高减量或再平衡 |

**当前策略**：不主动投资个股。若将来尝试，单笔不超过总资产 5%，且必须有书面卖出纪律。

### 4.3 卖出纪律

仅在以下情况卖出，**其余时间禁止操作**：

1. **年度再平衡**：每年 12 月最后一个交易日，将比例恢复至目标配置
2. **比例严重偏离**：任一资产比例偏离目标超过 **±5%** 时，在下次再平衡窗口调整
3. **基本面永久恶化**：持有基金的基金经理更换且策略根本改变、基金清盘等
4. **个股止损触发**：亏损达 15%（仅适用于个股，不适用于指数）

**禁止的卖出理由**：短期浮亏、社群恐慌、新闻事件、「回本就跑」的解脱冲动。

### 4.4 再平衡纪律

| 项目 | 规则 |
|------|------|
| 固定再平衡日 | 每年 **12 月 31 日**（或 12 月最后一个交易日） |
| 触发再平衡 | 任一资产比例偏离目标 **±5%** |
| 操作方式 | 机械恢复目标比例，不因主观判断增减幅度 |
| 操作上限 | 再平衡产生的买卖不超过该资产当前市值的 20% |

### 4.5 超额收益风险审查（面对诱惑时）

任何「超额收益」机会，必须完成三步审查：

**第一步：压力测试**
- 历史最大回撤是多少？以计划投入金额计算绝对亏损额
- 下跌时会与组合中哪些资产同跌？（相关性检查）
- 高收益来源于运气、高风险还是可持续能力？

**第二步：风险预算审计**
- 占「总风险预算」（即可接受最大亏损额）的百分比？
- 投入后是否导致核心资产配置不到位？
- 单一卫星资产是否超过 5%？

**第三步：决策隔离**
- 强制 **48 小时**冷却期
- 建立模拟仓位，观察至少两周
- 撰写「反方意见书」——列出至少三条可能失败的理由

## 第五章：风险控制

### 5.1 风险参数

| 参数 | 数值 |
|------|------|
| 组合最大回撤底线 | **5%** |
| 长期年化收益预期 | **4%–6%** |
| 实测情绪崩溃点（历史） | 约 -30%（2021） |
| 权益部分最大暴露（当前阶段） | **10%** |
| 权益部分最大暴露（终极） | **20%** |
| 单一卫星资产上限 | **5%** |
| 预备金（极端低估时追加用） | 不超过总资产 **5%** |

### 5.2 回撤响应机制

| 组合回撤幅度 | 响应动作 |
|-------------|----------|
| -2% | 正常检视，不操作 |
| -3% | 检查配置比例，确认是否在目标范围 |
| -4% | 书面记录心态感受，回顾宪法 |
| -5%（触及底线） | **停止一切新增风险暴露**；检视是否需降低权益比例；禁止因恐慌卖出 |

### 5.3 压力测试（每年执行一次）

在每年再平衡前，对当前组合进行情景测试：

| 情景 | 假设 | 检查 |
|------|------|------|
| 温和调整 | 股市 -10%，债市 -1% | 组合回撤是否 < 5%？ |
| 中度危机 | 股市 -20%，债市 -2% | 组合回撤是否可承受？心态会否崩溃？ |
| 极端情景 | 股市 -30%（2021 重演） | 当前配置下组合回撤多少？是否触发底线？ |

## 第六章：信息与心态管理

### 6.1 信息防火墙

| 信息类型 | 处理方式 |
|----------|----------|
| 社群短期涨跌猜测 | **噪音**，立即停止参与 |
| 平台产品推荐 / 基金情报局 | **销售内容**，可观察逻辑，禁止跟随操作 |
| 宏观研报 / 券商报告 | **辅助理解**，永不作为买卖唯一依据 |
| 经典书籍 / 系统学习 | **主要输入**，转化为宪法条款 |
| AI 建议 | **计算器+助理**，我做架构师和审稿人，追问逻辑链 |

### 6.2 情绪处理协议

当对持仓产生「发愁」「不甘心」「必须做点什么」时：

1. **停止**——不打开交易软件
2. **回溯**——买入时的初始理由和规则是什么？
3. **判断**：
   - 理由失效或触发止损 → 按宪法执行
   - 均未触发 → 忽略波动，坚持原计划
4. **记录**——在笔记中写下情绪和后续市场走势（建立「诱惑记录」档案）

### 6.3 叙事警惕

绝不使用以下理由为持有或操作开脱：
- 「长期看好中国经济」
- 「大国崛起」
- 「黄金十年」
- 「网上说明年有转机」
- 「中国最好的公司都在里面」

这些叙事可能正确，但**不能替代估值纪律和配置规则**。

### 6.4 群体行为观察原则

- 社群是**情绪温度计**和**反面教材库**，不是决策依据
- 当出现对单一方案的无条件维护、对异见的排斥 → 意识到非理性信号
- 外部方案：可借鉴框架，绝不复制结论；可关注逻辑，绝不跟随操作

### 6.5 心态友好原则

> 「这个操作或调整，是否会破坏我心态的友好状态？」

若答案是「会」，则无论收益多诱人，**一律不做**。

### 6.6 检视制度

| 频率 | 检视内容 | 操作权限 |
|------|----------|----------|
| 每日 | **不检视**（关闭推送，物理隔绝） | 无 |
| 每月 | 定投是否成功扣款；份额增长曲线 | 仅确认扣款 |
| 每季 | 配置比例是否偏离；基金基本面是否变化 | 仅记录，不操作 |
| 每年 | 全面复盘；再平衡；宪法修订评估 | 可执行再平衡 |
