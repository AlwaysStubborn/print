## 核心结论速览

1. **纪律是执行核心**：在正确认知和策略基础上，纪律是区分成功与失败投资者的最关键因素。
2. **知识是变化的，纪律是不变的**：先把握不变的东西，再用变化的知识辅助理解，而非颠覆纪律。
3. **方案制订上要勤奋，定完了之后就不能勤奋更换**：在配置阶段深度计算，执行阶段坚守系统。
4. **养老金思维**：只进不出，等待增值；拒绝短期投资逻辑。
5. **逐步脱敏**：从低波动投资起步，对波动不敏感后再考虑更积极的方式。
