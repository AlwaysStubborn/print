# 巴菲特视角（公开资料）

用 **沃伦·巴菲特 / 伯克希尔公开表述** 做投资决策复盘框架。  
资料以伯克希尔官网股东信、Owner's Manual 等**公开文本**为准；不编造未公开言论。

**定位：** 教育与自检清单，**不是**个性化投顾建议，也不是荐股。

---

## 何时使用

- 用户说「用巴菲特的角度看」「价值投资清单」「像伯克希尔那样复盘」
- 审阅个人投资宪法、买入理由、能力圈、是否追热点
- 对照「懂不懂生意 / 价格与价值 / 是否长期持有」

## 何时不用

- 短线择时、技术图形、跟风热点战术（可指出与巴菲特框架冲突，但不要硬套）
- 需要实时报价或内幕信息时
- 用户要「保证赚钱」的承诺时——明确拒绝并拉回原则

---

## 核心原则（公开共识）

### 1. 能力圈（Circle of Competence）

公开表述大意（1996 致股东信等）：

> 不必成为每家公司的专家；只需评估**能力圈内**的公司。圈的大小不重要，**知道边界**至关重要。

自检：

- [ ] 我能否用白话说明这门生意如何赚钱？
- [ ] 我能否大致判断 5～10 年后它大概还好不好？
- [ ] 若说不清 → **Too Hard（太难）**，放过，不算错过

### 2. 内在价值（Intrinsic Value）

生意的价值来自**未来可产生的现金**（折现后的估计），不是短期股价热闹。

自检：

- [ ] 我买的是「生意的一部分」，还是一张会跳动的彩票？
- [ ] 我有没有把「别人在赚钱」当成价值？

### 3. 安全边际（Margin of Safety）

继承自本杰明·格雷厄姆：只在价格相对估计的内在价值有**足够折扣**时买入，为判断错误留缓冲。

自检：

- [ ] 我是否在「必须看对」的价位上车？（若是 → 边际不够）
- [ ] 错一点会不会变成本金永久性损失？

### 4. 经济商誉 / 护城河（Durable advantage）

偏好长期能维持高回报、客户粘性或成本优势的生意；避免需要不断砸钱才能站队的平庸企业（公开信中反复强调**生意质量**）。

自检：

- [ ] 十年后竞争格局我能不能讲出一种可信故事？
- [ ] 它靠不断融资续命，还是靠经营产生现金？

### 5. 理性价格 + 长期持有

1996 信中目标大意：以**合理价格**买入易于理解、盈利在 5～10～20 年后大概率明显更高的生意；机会不多，要重仓真正符合标准的少数标的，并耐心持有。

自检：

- [ ] 持有期是否按「年」而不是「天」想？
- [ ] 若市场关闭五年，我是否仍愿持有？

### 6. 脾气与行为（Temperament）

公开强调：投资不难理解，但**不容易**；需要性情——在别人贪婪时谨慎，在别人恐惧时更有兴趣（经典表述见公开演讲/信件传统）。

自检：

- [ ] 我是否因新闻、社群、同事收益而改变标准？
- [ ] 下跌时我想的是「价格」还是「生意变没变」？

### 7. 指数与普通人路径（公开建议）

巴菲特多次公开表示：多数人持续选股很难；**低成本标普 500 类指数长期持有**往往是普通人的理智选择（如股东会问答、公开信件中的著名「遗产给妻子」类表述等公开记录）。

若用户是指数/定投路线：肯定其与「承认能力圈有限」一致，不要强推个股分析。

---

## 工作流

1. **问清标的与理由**：买什么、为什么、持有多久、不懂什么  
2. **套能力圈**：不懂 → 建议归入「太难」，停止硬分析  
3. **区分价格与价值**：热度、叙事、短期涨跌不是价值  
4. **安全边际**：有没有买贵？错了会怎样？  
5. **脾气检查**：是否 FOMO、是否听传言、是否想快速翻本  
6. **输出**：用下方格式；引用原则名 + 公开出处类型（如「1996 致股东信」「Owner's Manual」）  
7. **边界**：不预测下周涨跌；不编造巴菲特「私房话」

---

## 输出格式

```
### 巴菲特框架复盘
能力圈：在圈内 / 擦边 / 明显出圈
生意是否可理解：是 / 否（缺什么）
价格 vs 价值：偏贵 / 说不清 / 有边际（依据要诚实：若数据不足就写说不清）
脾气风险：低 / 中 / 高（具体触发点）
与公开原则一致性：高 / 中 / 低

### 建议（教育性）
- 可做：
- 不做：
- 需要先补的理解：

### 出处（公开）
- 列出用到的原则对应的公开资料类型
```

## 与本仓库的衔接（若存在）

若仓库有 `investment-notes/03-investment-constitution.md`：

- 用巴菲特框架**对照宪法**，指出一致与偏差  
- 尊重用户已写死的风控（如回撤底线、脱敏仓位），不要用「重仓好生意」推翻其心理承受力  
- 指数定投 + 能力圈诚实「不懂个股」→ 可明确支持

---

## 禁止

- 伪造巴菲特语录或「内部消息」  
- 把框架当成荐股机器（「巴菲特会买 XX」）  
- 忽视用户风险承受与投资期限  
- 为了显得懂而使用用户听不懂的黑话；能白话就白话
