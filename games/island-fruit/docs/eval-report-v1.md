## 一、UI 交互

```
UX 总分：21/30
结论：需改版（可玩，但有几处会懵/偏被动）
```

| 项 | 分 | 说明 |
|----|----|------|
| 开玩 | 3 | 能开，但首屏字偏多；「天气种子」对新人费解 |
| 反馈 | 4 | 采后有地块高亮、背包、日志 |
| 误触 | 5 | 传言时禁用「下一步」 |
| 手机 | 3 | 有响应式，三按钮挤；未真机细测 |
| 节奏 | 3 | 12 天里多数回合只点一个键，偏「看戏」 |
| 看得清 | 3 | 整体清楚；坚果林文案有「收息/底仓」漏词 |

**一票否决：** 未触发（能同天气重开；有过程分）

**Top 3**
1. 游玩中几乎只能点「按策略采摘」→ 参与感弱  
2. 「天气种子」+ 首屏长说明 → 30 秒理解吃力  
3. 地块文案「像收息的底仓」→ 小白会愣，也不该提前泄题  

**可马上改**
- 坚果林描述去掉金融词，改成「稳、每天一点点」  
- 种子标签改成「天气编号（一样=同一串晴雨）」  
- 首屏 lead 再砍短一半  

**不要改成**
- 不要加游戏内评测角色  
- 不要终局揭「其实是投资」

## 二、炒股小白

```
小白视角：勉强
```

**口述（代入小白）**
1. 练什么？→ 大概是：天气乱、别乱听人、自己定规矩采  
2. 规矩对了为何少果子？→ 这局模拟里混合规矩 90、跟风 115，**能感到「对也可能少」**（若玩家肯同编号再开）  
3. 传言像什么？→ 像听别人说「必翻倍」「赶紧跑」  
4. 跟风赢了会不会觉得跟风对？→ **有风险**：这局跟风果子更多，若不做第二次对比，容易悟歪  

**可能悟到的**
- 天气管不住  
- 听传言会扣「守没守住」  
- 坚果稳、传说晃  

**可能悟歪的**
- 「跟岛民果子更多，所以该跟」← 本种子实况会强化这点  
- 「混合规矩老是不采晴天，是不是坏了」  
- 「种子」是彩票号、要去碰运气  

**最容易懵的一步**
- 开始页的「天气种子」  
- 混合规矩在大晴天仍采坚果（空采）却几乎不解释「为什么今天算熟度不够」  

**建议（仍不揭隐喻）**
- 终局若跟风果子更高，加一句中性提示：「果子多不等于采法更稳，可用同一天气换采法再比。」  
- 空采那天日志写清：「今天按规矩空过甜果（可能少赚，也可能少挨打）」  
- 引导第二次开局：按钮文案已有，可在终局更醒目一点

## 三、产品经理

```
产品结论：方向对
是否服务目标：是（机制上已有「选对也可难看」；引导二次对比还不够硬）
反模式：通过
```

**反模式**
- 近赢勾人 / 排行榜 / 充值 / 惩罚不玩 → 都没有  
- 单局定生死 → 有轻微风险（终局数字很大），靠「同一天气换策略」按钮补救，但可再强调  

**P0**
1. 去掉界面里的「收息/底仓」等漏词  
2. 终局加强「再开同一天气对比」的提示（尤其当跟风分更高时）  

**P1**
3. 降低「只看戏」感：传言外偶尔让玩家确认「今天采这里」或展示「本策略今天选了 X」  
4. 「熟度」对玩家可见一点（不必公式，只要「够/不够」）  

**P2**
5. 首屏再缩短；种子改名  
6. 调参让「跟风」期望别系统性压过「混合规矩」（保持方差大，但别让教学种子老是跟风赢）  

**明确不做**
- 游戏内评测 UI、揭隐喻、排行榜、真实行情
