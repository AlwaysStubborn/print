## 二、炒股小白

```
小白视角：通过（v1：勉强）
```

**口述（代入）**
1. 练什么？→ 天气乱、自己定采法、别乱听人  
2. 规矩对了为何少果子？→ 能感到（同编号下规矩 96、跟风 115）  
3. 传言像什么？→ 别人喊翻倍/快跑  
4. 跟风赢了会不会觉得跟风对？→ **终局黄盒会泼冷水**（果子多≠更稳；看回撤），悟歪风险低于 v1  

**可能悟到的**
- 天气管不住  
- 熟度够/不够决定采不采甜果  
- 同一天气换采法才能比  

**可能悟歪的（减轻但仍有）**
- 只看期末数字、不看回撤 → 仍可能觉得跟风更好（需玩家肯点第二次）  

**最容易懵的一步**
- 仍是「熟度」为什么今天不够（已有说明，比 v1 好）  
- 第一次看到天气编号仍可能略懵，但比「种子」好懂  

**建议（可选 P2）**
- 终局对比盒若检测到跟风分更高，可并排写「果子 115 / 回撤 -21.8%」模板句（同编号二次后已有数字对比）  
- 不必揭隐喻
